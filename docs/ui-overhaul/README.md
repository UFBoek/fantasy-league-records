# Review screenshot provenance

These images are browser screenshots of FIG League on `design/fig-platform-overhaul`, captured locally with Playwright and Chromium on October 23, 2026. Desktop viewport: 1440×1000. Mobile viewport: 390×844. The PNG metadata also records source, capture date, viewport, and browser tooling.

The images use the repository's real archived league data and existing franchise artwork. They are not generated mockups. External Sleeper/headshot endpoints were unavailable in the test environment; reconnect and player-initials states reflect that limitation. Synthetic live-score fixtures are used only in the separate delivery test and are not represented in these screenshots.
